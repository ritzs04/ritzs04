### 🚀 Featured Project

**[BuilderVerse](https://github.com/ritzs04/BuilderVerse)** — a full-stack interactive learning platform where students learn programming by doing: read concepts, run code in a browser lab, solve puzzles, debug real errors, and ship guided projects into a public portfolio.

- **Stack:** Next.js 16 · React 19 · TypeScript · Tailwind CSS v4 · SQLite · Docker
- **Features:** 6 learning paths · 27 lessons · XP & badges · AI chat tutor · Playwright CI
- **Live:** [builder-verse-delta.vercel.app](https://builder-verse-delta.vercel.app)
